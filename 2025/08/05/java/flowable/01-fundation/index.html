Flowable - Fundation

Flowable is a lightweight business process engine written in Java. It is designed to be fast, efficient, and easy to use, making it a popular choice for developers looking to implement workflow and business process management (BPM) solutions.

Key Features of Flowable

  1. BPMN 2.0 Support: Flowable fully supports the BPMN 2.0 standard, allowing developers to model complex business processes using a graphical notation.
  2. Easy Integration: Flowable is easy to integrate with existing Java applications and frameworks.
  3. High Performance: Flowable is designed to be fast and efficient, making it suitable for high-volume workflow processing.
  4. Extensible: Flowable is highly extensible, allowing developers to customize and extend its functionality to meet specific requirements.

Core Concepts

There are a few important concepts to understand first.

ProcessDefinition

A ProcessDefinition is the template of a workflow. It is usually defined in a BPMN file.

For example: Simple Approval Process can be deployed as a reusable process definition.

ProcessInstance

A ProcessInstance is one running instance of a process definition.

For example, if three employees submit approval requests, the same process definition can create three separate process instances.

Task

A Task represents work that needs to be completed by a user.

For example: Manager Approval, When Flowable reaches a UserTask, it creates a task and waits for a user to complete it.

Execution

An Execution represents the current execution path inside a running process.

For simple workflows, you can think of it as: Where is the workflow currently running?

For parallel workflows, one process instance may contain multiple executions.

Process Variable

Process variables are data used during workflow execution.

When the process starts, Flowable follows the BPMN definition. Once it reaches Manager Approval, Flowable creates a task and pauses the process.

An important point is that Flowable does not keep a Java thread running while waiting for the manager. Instead, it stores the workflow state in the database.

The simplest way to think about Flowable is:

BPMN defines how a business process should flow, while Flowable is the engine that executes that process.
